# Installation — Premiere Pro 23.2

1. Copy the `Beat-marker-test` extension folder to:
   `%APPDATA%\Adobe\CEP\extensions\com.mrblack.beatmarker`
2. If Premiere does not list the extension, enable CEP unsigned-extension/debug mode for the installed CEP runtime.
3. Restart Premiere Pro.
4. Open **Window > Extensions > Beat Marker**.
5. Select the same music/audio file used in the sequence.
6. Click **Analyze Beats**.
7. Adjust sensitivity and minimum spacing if necessary.
8. Click **Create Markers**.

This is a CEP/ExtendScript panel, not a UXP `.ccx` plugin.
